CLI Tool

ProvenGraph CLI

Binary name provengraph. Speaks --json for agents, human-readable for developers. Every error includes a suggested_command — copy-paste the fix.

registerRegister a new MCP serverprovengraph register --name my-server --server-url https://...
listList servers — filter by query, capability, statusprovengraph list --capability web-search --json
resolveFind UP servers by capability, ranked by uptimeprovengraph resolve weather
statsLive registry statisticsprovengraph stats --json
statusSingle server detail by name or IDprovengraph status my-server
capabilitiesAll capabilities with server countsprovengraph capabilities
delistSoft-delete a server (requires write key)provengraph delist my-server --write-key <key>
doctorHealth check — exits 0 if reachableprovengraph doctor
Knowledge
knowledge-createCreate a knowledge claimprovengraph knowledge-create --content "..." --domain mcp-security --issuer TruCore
knowledge-getGet a claim with provenance scoreprovengraph knowledge-get --id claim:abc123
knowledge-listList claims by domain or search queryprovengraph knowledge-list --domain mcp-security
knowledge-supersedeAssert v2 supersedes v1provengraph knowledge-supersede --id v2 --supersedes v1 --write-key <key>
knowledge-contradictAssert claim contradicts anotherprovengraph knowledge-contradict --id claim:A --contradicts claim:B --write-key <key>
knowledge-attestAttest to a claimprovengraph knowledge-attest --id claim:abc123 --issuer TruCore
Memory
memory-createCreate a memory entryprovengraph memory-create --content "user prefers dark mode" --owner agent:hermes
memory-getGet a memory entry by IDprovengraph memory-get --id memory:abc123
memory-listList memories by agent or categoryprovengraph memory-list --agent hermes --category preference
memory-rememberAgent remembers a memory entryprovengraph memory-remember --id memory:abc123 --agent agent:atlas
memory-forgetAgent forgets (remove remembers edge)provengraph memory-forget --id memory:abc123 --agent agent:atlas
memory-deleteHard delete (right to be forgotten)provengraph memory-delete --id memory:abc123 --write-key <key>
