CLI Tool

meshdns-cli — a single Go binary, zero dependencies. Every command speaks both --json for agents and human-readable for developers. Installed alongside the server binary.

Command What it does Example
register Register a new MCP server in the registry meshdns-cli register --name my-server --server-url https://...
list List servers with filters (query, capability, status) meshdns-cli list --capability web-search --json
resolve Find UP servers by capability, ranked by uptime meshdns-cli resolve weather
stats Live registry statistics (active, up, resolutions/24h) meshdns-cli stats --json
status Detailed view of a single server by name or ID meshdns-cli status my-server
capabilities List all capabilities with server counts meshdns-cli capabilities
delist Soft-delete a server (requires write key) meshdns-cli delist my-server --write-key <key>
doctor Health check — exits 0 if the registry is reachable meshdns-cli doctor
go install github.com/trucore-ai/meshdns/cmd/meshdns-cli@latest — or — meshdns-cli --help after building from source

Built for agent-first design. Every command supports --json for machine-readable output. Errors include a suggested_command field — copy-paste the fix directly. Default output is human-readable. View source →
